# Surface: web dashboard

Mode: Operate. Direction pinned by the user's brief ("Notion-meets-Linear: sidebar, universal search, visual
project dashboards"), executed as the category standard at full fidelity; no concept roll was run because the
brief fixed the world.

## Direction contract

THESIS: A calm, dense workbench where every claim shows its provenance (status, origin model, evidence) before
anything else. It refuses the card-grid "AI dashboard" with hero metrics and glowing gradients.

OWN-WORLD: Cool graphite neutrals with a faintly indigo-tinted sidebar; iris accent for selection and focus
only. Colour does jobs: five status hues (green supported, slate unverified, amber challenged, red contradicted,
muted strike for superseded) and hashed per-model hues that favour no provider. System UI type, tabular
numerals, mono only for record ids. Hairline rows, no nested cards.

STORY: Owner opens the project, sees how much of what the AIs said is actually checked, what needs attention,
and what changed since last time (including live writes from Claude over MCP), then drills into any record.

FIRST VIEWPORT: Sidebar (brand, Search ⌘K, Home, projects each with a trust bar, live indicator). Main: project
title, model chips, the trust bar at full width with legend, then two columns: Needs attention (gaps) and
Activity.

SIGNATURE: The trust bar: a segmented bar of record statuses that appears full-size on the overview and
miniature beside each project in the sidebar, and filters records when clicked.

RISK: Dense information can feel clinical; warmth comes from precise copy and the live activity feed.
