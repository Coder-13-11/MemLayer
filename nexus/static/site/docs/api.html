REST API

The API under {{API_URL}} is the same one the app uses, authenticated with an API key instead of a browser session.

curl {{API_URL}}/projects -H "Authorization: Bearer nxk_..."

A key belongs to one workspace and is either read-only or read-and-write. It can never confirm an entry, manage members or create other keys. Each key is limited to a number of requests per minute set by the workspace's plan; over the limit you receive 429 with a Retry-After header. Errors are JSON: {"error": "..."}.

Reading

RequestReturns
GET /v1/metaThe workspace, the key's role and scopes.
GET /v1/projectsProjects with counts by status.
GET /v1/projects/{project}One project's overview. {project} is an id or a name.
GET /v1/projects/{project}/context?q=The structured context an MCP client receives.
GET /v1/projects/{project}/briefing?budget=&policy=&q=The briefing text, the entries in it and a receipt id. Add receipt=0 to preview without a receipt.
GET /v1/projects/{project}/records?kind=&status=&q=Entries, filtered.
GET /v1/records/{id}One entry with evidence, links, source and history.
GET /v1/projects/{project}/gapsThe Review list.
GET /v1/projects/{project}/graph, /sources, /exportLinks between entries; original sources; a full JSON export.
GET /v1/search?q=Keyword search across the workspace.
GET /v1/receipts/{id}A receipt.

Checking a plan

curl -X POST {{API_URL}}/projects/Checkout%20rebuild/check \
  -H "Authorization: Bearer nxk_..." -H "Content-Type: application/json" \
  -d '{"statements": ["Add Jest tests for the cart",
                      {"text": "Store prices as floats", "subject": "money.representation", "value": "float"}]}'

Each result has a verdict of conflict, resembles_replaced, review or clear, with the entries behind it. A read-only key can call this.

Writing

RequestDoes
POST /v1/projectsCreate a project: name, objective, description.
POST /v1/projects/{project}/recordsAdd an entry: kind, title, content, origin_model, importance, subject, value, evidence[], relations[].
PATCH /v1/records/{id}Correct an entry. Requires a reason. The previous version is kept.
POST /v1/projects/{project}/importStore a document as a source and extract entries from structured Markdown.
DELETE /v1/records/{id}Delete an entry. Deleting a project is not available to keys.

The model gateway shares the /v1 prefix and the same keys: see Gateway.
