What it does not do

These are the edges of the current version, stated plainly so you can decide whether it fits.

The record

  • It does not write itself. An entry exists because a person or an AI tool saved it. A decision made in a chat and never saved is not in the record.
  • It does not judge evidence. It records that a source is attached and who confirmed the entry. It does not open the source.
  • Confirmation is one person's word. There is no second reviewer or approval rule yet.

Conflicts and the check

  • No AI model is involved. Conflicts are found from explicit links, from entries sharing a claim key with different values, and from wording overlap with replaced entries.
  • Two entries that disagree only in meaning are not detected unless someone links them, or a connected AI tool is asked to review the project and records the conflict.
  • “Resembles a replaced record” compares words. A step that rejects the old approach can match it, and a paraphrase with different words will be missed. The repository's verification report gives measured numbers on a labelled test set.
  • “Clear” is not approval. It means nothing was found.

AI tools

  • It cannot make a model obey. It places the decision in front of the model and records that it did.
  • Models do not always call tools unprompted. Use the gateway or a session-start hook when reading must be guaranteed.
  • Stored text is untrusted. It is always delivered as labelled data with a notice not to follow instructions inside it, but a model can still be misled by what a teammate or another model wrote. The confirmed briefing setting exists for this.

The gateway

  • It forwards each wire format to providers that speak it. It does not translate between them, route by cost, retry or fall back.
  • It is tested against stand-in servers, not live provider accounts.
  • A pinned briefing can be up to 15 minutes behind the record.

The service

  • No single sign-on, no two-factor sign-in, no SCIM.
  • No billing. Limits exist; nothing is charged.
  • Rate limits are counted per instance, in memory.
  • Search is keyword search. There is no embedding or semantic search.
  • It has had no outside security audit.
