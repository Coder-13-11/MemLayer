Apps with connectors

{{BRAND_NAME}} is a remote MCP server with OAuth sign-in. Any app that supports custom connectors can use it with one address.

{{MCP_URL}}

What happens when you connect

  1. The app registers itself and sends you to a {{BRAND_NAME}} page.
  2. You sign in (or are already signed in), choose a workspace, and choose whether the app may add to the record or only read it.
  3. The page names the app and the site you will be sent back to. Apps can call themselves anything; the return address cannot be faked.
  4. The app receives a token for that one workspace. It lasts an hour and is renewed with a single-use refresh token.

Remove a connection at any time under Settings, Connect AI tools. Removing a member, or lowering their role, takes effect on their apps' next request.

Tools the app gets

ToolDoes
get_project_contextReads the project: decisions, findings, assumptions, questions, history, open conflicts. Leaves a receipt.

list_projects, get_review_instructionsLists projects; gives the app instructions for a careful review.

There is no tool that deletes or confirms. Each entry an app writes records the model's name, the app's name and the person who connected it.

Getting tools to use it without being asked

Models decide for themselves when to call a tool, and they do not always. Three things make reading reliable:

  • Add a line to the tool's own instructions file, such as AGENTS.md or CLAUDE.md: “At the start of work, read the project record in NEXUS. Before proposing a plan, call check_plan.”
  • Print the briefing into the session yourself with a session-start hook: see Command line.
  • Use the gateway, which adds the briefing to every request.

Compatibility

The server implements the MCP authorization flow with dynamic client registration, PKCE and protected-resource metadata, over the stateless Streamable HTTP transport. It is tested with the official MCP client library. It is built on the 1.x line of the Python SDK; support for the 2026-07 revision of the specification is on the roadmap.
