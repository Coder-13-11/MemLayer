Self-hosting

{{BRAND_NAME}} is one Python process. It needs either a folder for SQLite files or a Postgres database, and an HTTPS address in front of it.

With Docker and Postgres

cp .env.example .env        # set NEXUS_PUBLIC_URL and NEXUS_SECRET_KEY
docker compose up -d

The compose file starts the service and Postgres 17. Put a TLS-terminating proxy in front of port 8000.

Without Docker

python -m venv .venv && . .venv/bin/activate
pip install .
export NEXUS_PUBLIC_URL=https://nexus.example.com
export NEXUS_SECRET_KEY=$(nexus admin generate-key)
nexus hosted --data-dir /var/lib/nexus

Settings

VariableMeaning
NEXUS_PUBLIC_URLThe https address people and AI apps connect to. Required.
NEXUS_DATABASE_URLPostgres URL. DATABASE_URL is accepted too. Without it, SQLite files are used.
NEXUS_DATA_DIRFolder for SQLite files. Default ~/.nexus/hosted.
NEXUS_SECRET_KEY32 random bytes, base64 or hex. Seals stored provider keys. Required on Postgres to store them.
NEXUS_SECRET_KEYS_OLDEarlier keys, comma separated, accepted for reading during rotation.
NEXUS_SIGNUPopen, invite (needs NEXUS_SIGNUP_CODE or a workspace invitation) or closed (invitations only).
NEXUS_SMTP_URL, NEXUS_MAIL_FROMOutgoing mail, for example smtp://user:password@host:587. Optional.
NEXUS_BRIEFING_PIN_SECONDSHow long a gateway briefing is held unchanged. Default 900.
NEXUS_MOCK_PROVIDER0 turns off the built-in mock model.

How data is stored

A control database holds accounts, workspaces, keys, usage and the audit log. Each workspace's record is stored separately: its own SQLite file under workspaces/, or its own Postgres schema. Deleting a workspace removes that file or schema.

Migrations are numbered SQL files that run on both databases. The service applies pending ones at start; nexus admin status shows them and /readyz reports them.

Health

/healthz answers when the process is up. /readyz answers 200 when the database is reachable and migrations are applied.

Backups

On Postgres, back up the whole database: the control schema and every workspace schema. On SQLite, back up the data folder, including secret.key if you did not set NEXUS_SECRET_KEY. Without the secret key, stored provider keys cannot be read. Any admin can also export a workspace as JSON from the app.

Scaling

One instance serves a team comfortably. Rate limits and briefing pins are held in memory per instance, so with several instances each counts for itself. Each instance uses one database connection. The roadmap in the repository says what changes first under load.

Rotating the secret key

NEXUS_SECRET_KEY=<new> NEXUS_SECRET_KEYS_OLD=<old> nexus admin rotate-keys

Then remove the old key from the environment.
