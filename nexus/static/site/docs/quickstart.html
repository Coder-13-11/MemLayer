Quickstart

You will create a workspace, load an example project, connect one AI tool and watch it read the record.

1. Create a workspace

Create an account. You are asked for a workspace name, usually your team. You become its owner.

2. Load the example project

On the first screen choose Load the example project. It is an invented checkout rebuild with 18 entries: decisions that were replaced, an assumption that turned out wrong, and two tools that disagree about a measurement. Open Review to see what needs attention and Briefing to see the text a model is handed.

3. Connect a tool

Pick the way in that matches your tool.

Create an API key under Settings, API keys, then follow Gateway.

4. Ask it something the record answers

In the connected tool, ask: “We are adding tests to the cart. What should I use?” It should read the project and answer Vitest, and mention that Jest was replaced. Then open Receipts in {{BRAND_NAME}}: there is a new one, listing the entries the tool was given.

5. Try the check

Under Briefing, Check a plan, enter Add Jest tests for the cart reducer. The check reports that it resembles a replaced record and names what replaced it.

No tool handy? The Playground sends a message through the gateway using a built-in mock model. It calls no provider and needs no key. The mock is not an AI: it repeats back what it was given, so you can see the briefing arrive.
