Command line

The nexus command talks to a server when NEXUS_URL and NEXUS_API_KEY are set, and to a local database file when they are not.

pip install .               # from a checkout of this repository
export NEXUS_URL={{PUBLIC_URL}}
export NEXUS_API_KEY=nxk_...

Print the briefing

nexus brief "Checkout rebuild"
nexus brief "Checkout rebuild" --budget 600 --policy confirmed

This prints exactly what a model is handed. Run it at the start of a coding-agent session so the agent reads the record without having to decide to. In Claude Code, a session-start hook that runs the command adds its output to the session:

{
  "hooks": {
    "SessionStart": [
      {"hooks": [{"type": "command", "command": "nexus brief \"Checkout rebuild\""}]}
    ]
  }
}

Check a plan

nexus check "Checkout rebuild" "Add Jest tests for the cart" "Rename the README"
nexus check "Checkout rebuild" --file plan.txt

The command exits with status 2 when a step conflicts with a recorded decision or resembles something the team replaced, so it can fail a pipeline step. Add --warn-only to always exit 0, and --json for machine-readable output.

Local, single-user mode

Without a server, the same commands and a local dashboard work against one SQLite file:

nexus web                 # a dashboard on http://127.0.0.1:8765
nexus serve               # an MCP server on standard input and output
nexus import notes.md     # store a document and extract its entries

Operating a server

nexus admin migrate              # apply pending database migrations
nexus admin status               # show applied and pending migrations
nexus admin workspaces           # list workspaces with size and plan
nexus admin set-plan acme team   # change a workspace's plan or limits
nexus admin outbox               # read mail that was not sent
nexus admin reset-link a@b.com   # a password link, when mail is not set up
nexus admin generate-key         # a new NEXUS_SECRET_KEY
nexus admin rotate-keys          # re-seal provider keys with the current key
