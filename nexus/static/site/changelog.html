What changed, newest first.

0.2.0

The product became {{BRAND_NAME}}: a shared record for teams, not a personal memory.

  • Workspaces with members, four roles and single-use invitations.
  • Confirmation: only a signed-in person can vouch for an entry; rewording clears it.
  • The plan check, in the app, over MCP (check_plan), the API and the command line.
  • Briefings with a size limit, and context receipts for every one handed to a model.
  • A pass-through gateway for the Chat Completions, Responses and Anthropic Messages formats, with stored or passed-through provider keys.
  • API keys and a REST API.
  • Usage, plan limits and an audit log.
  • Numbered database migrations for SQLite and Postgres. Accounts from 0.1 keep their memory and connected apps.
  • Password change and reset, account and workspace deletion, full export.

0.1.0

MemLayer: a personal, evidence-aware project memory with an MCP server, OAuth sign-in, a dashboard and a rule-based gap analysis.
