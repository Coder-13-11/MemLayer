What it does not do.

A record you cannot trust is worse than none, so here is where the edges are. The full list of limits.

It calls no AI model

Conflicts are found from structure and wording, so a contradiction nobody recorded stays hidden.

It does not judge evidence

It records that a source is attached and who confirmed the entry. Whether the source is right is a person's call.

It cannot make an agent obey

It puts the decision in front of the model and records that it did. Following it is still up to the model.

It keeps no conversations

The gateway stores counts, model names and record numbers. Prompts and answers pass through and are not kept.
