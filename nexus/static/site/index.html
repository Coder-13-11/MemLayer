Three tools, three versions of what you decided.

Each AI tool keeps its own notes. One remembers a decision you reversed in June. Another reads a rules file nobody updated. A third was never told. They are all confident, and none of them can see the others.

The cost shows up as work: a pull request that reintroduces the library you removed, an agent that argues for the approach you rejected, a teammate's assistant that contradicts yours.

Every line says who wrote it and whether anyone checked.

The record is not a pile of remembered text. Each entry is a decision, an assumption, a finding or an open question, with its author, its evidence and its history. A model can write an entry. Only a person can confirm one, and rewording a confirmed entry clears the confirmation.

  • Nothing is overwritten

    A replaced decision is voided, not deleted. Its history stays, with who changed it and why.

  • Conflicts stay visible

    When two tools disagree, both entries are shown as a conflict until a person settles it. Nothing picks a side quietly.

  • AI tools cannot delete or confirm

    They read, add and correct. Deleting and vouching are for people, and every change is attributed.

It stops a plan before it repeats something you already fixed.

Before an agent acts, it sends its plan to the record. If a step matches a decision the team replaced, or gives a different value for something already decided, the agent is told, with the entry that replaced it.

The check is word matching and value comparison. It involves no AI model, so it is fast, repeatable and narrow: it will miss a paraphrase, and it never says a plan is right.

What it does not do.

A record you cannot trust is worse than none, so here is where the edges are.

Read the full list of limits
  • It calls no AI model. Conflicts are found from structure and wording, so a contradiction nobody recorded stays hidden.
  • It does not judge evidence. It records that a source is attached and who confirmed the entry. Whether the source is right is a person's call.
  • It cannot make an agent obey. It puts the decision in front of the model and records that it did. Following it is still up to the model.
  • It keeps no conversations. The gateway stores counts, model names and record numbers. Prompts and answers pass through and are not kept.
