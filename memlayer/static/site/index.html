2What every record keeps

A memory is only useful if you can tell what to trust. Nothing is stored as a bare sentence: each record carries its standing, and changing it leaves the old version in its history.

Finding what is missing

The gap analyzer reads the whole project and lists contradictions, claims without evidence, assumptions nobody tested, decisions resting on unfinished work and questions still open. Every gap names the records it is based on and says how sure it is. For conflicts that only show in the wording, ask your own assistant to review the project: it records what it finds back into memory, with a note, for you to settle.

3Data and security

Your memory, separately
Each account has its own database file. Every request is answered from the file that belongs to the signed-in account, so one person's records cannot appear in another's results.
Sign-in
OAuth 2.1 with PKCE and per-app registration[2][3]. The approval screen shows which app is asking and where you will be sent back to.
Secrets at rest
Passwords are stored as scrypt hashes; access codes and tokens only as SHA-256 hashes. Access lasts an hour and renews; revoking an app ends it immediately.
What assistants can do
Read, add and update. Assistants cannot delete anything, and every change keeps the previous version.
Untrusted text
Imported conversations are stored as data. They are never rendered as HTML or followed as instructions.
No model of our own
{{BRAND_NAME}} calls no AI model and does not use your memory to train one. Only the assistants you approve can read it.

4Limitations

  • Assistants decide when to use memory. Asking "check my project memory" is the reliable trigger.
  • The built-in gap analyzer works from rules, links and stated values. Contradictions that live only in the wording need your assistant's review.
  • Custom connectors depend on each assistant's plan and rollout (Table 1). Menu names change without notice.
  • Memory is personal for now. Shared team projects, account export and deletion from the web are planned before public launch.
